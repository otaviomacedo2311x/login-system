# 🔐 Sistema de Login e Autenticação

Uma aplicação web desenvolvida para gerenciar o acesso de usuários através de um fluxo completo de autenticação e validação de dados.

---

## 📌 Sobre o Projeto

Este projeto consiste em uma interface moderna e responsiva de **Sistema de Login**, desenvolvida para garantir uma experiência de usuário simples, fluida e intuitiva.

### 🚀 Funcionalidades
- [x] Interface limpa e responsiva (adaptada para desktop e mobile)
- [x] Validação de campos (e-mail e senha)
- [x] Alternância entre tela de Login e Cadastro
- [x] Feedback visual de erros e campos obrigatórios

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação semântica
- **CSS3** — Estilização, layout (Flexbox/Grid) e responsividade
